# 🏧 ATM System - C++

A console-based ATM System developed in **C++** that simulates basic ATM operations such as login, withdrawals, deposits, and balance checking.

## 📌 Features

- 🔐 Account login using Account Number and PIN Code
- 💸 Quick Withdrawal
- 💰 Normal Withdrawal
- ➕ Deposit
- 💳 Check Account Balance
- 🚪 Logout
- 💾 Save and load client data using text files
- 📂 File handling using `fstream`
- 🧩 Organized code using functions, structures, vectors, and enums

## 🛠️ Technologies Used

- **C++**
- **Visual Studio**
- **File Handling**
- **STL Vector**
- **Structures**
- **Enums**
- **Functions**
